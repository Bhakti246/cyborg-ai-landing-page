# CYBORG AI Landing Page

A modern futuristic cyberpunk-themed landing page built using HTML, CSS, and JavaScript.

## 🚀 Project Overview

CYBORG AI is a responsive landing page designed with a futuristic AI and cyberpunk aesthetic. The project showcases modern web design techniques including glowing effects, smooth scrolling, animations, responsive layouts, and interactive UI components.

## ✨ Features

* Responsive Navigation Bar
* Futuristic Hero Section
* Cyberpunk Color Scheme
* Neon Glow Effects
* AI Technology Cards
* Features Section
* Smooth Scrolling Navigation
* Scroll Reveal Animations
* Contact Form
* Mobile-Friendly Design
* Modern UI/UX

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
